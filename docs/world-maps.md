# The world's maps

Generated by `tools/world/map_inventory.py` (`npm run maps`); edit `data/world/regions.json`, not this page.

Every map is a `.roo` file. The client picks a built zone by its room file and checksum, so one remastered `.roo` serves every Kod room that uses it (the Death Realm reuses the overland maps).

**Status:** *remastered* = built, with an art config (`data/environment/zone_<rid>.json`), look-dev cameras and the maintainer's approval; *art in progress* = an art config, not approved yet; *built* = a UE level (upscaled textures, props) without an art pass; *runtime* = built from the server's file when entered, with the original look; *later* = left for its own plan (the Death Realm); *kept original* = kept as the original on purpose, for history (built from its file, never remastered); *not remastered* = no Kod room uses it.
