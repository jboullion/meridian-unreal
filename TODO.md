## Brand new features


### Skyrim Inspiration

- I think we should draw a LOT of inspiration from Skyrim for this new remastered game. We should keep the world and the lore the same, but update a lot of other very outdated things to work similar to Skyrim.



### Tutorials and dialogs

- A lot of the old game had the turorials just as messages you could read in the game.
  - Similarly a lot of the text that an NPC or system message would appear in the chat and can be easy to miss.
  - We might want to think of new ways to show the player important system messages and leave the chat area for the actual chat.
  - So NPCs for instance should perhaps have an "Interaction" feature similar to quest givers in other games where you can read the messages they send to you through a dialog.
  - Similarly we could display tutorial and other information to our uses through these dialogs as well.


### Questing

- Perhaps we could set up some kind of quest tracking feature where a user can have a quest active and it shows up on the mini map / world map where they need to go.

- Similarly there are quests with moving NPCs in different zones that could probably actually inform the user where to find these NPCs as they move around the world.

### PvP

- In town crowds and guards.
  - One problem with the old game is a powerful PvP player can cause a lot of havoc, Especially inside a city.
  - We might want to set up some kind of guard system (which does partially exist in the game now) where we have NPC guards which attack PvP / Murderer flagged players in towns and just outside of towns. These guards are not super powerful, but powerful enough to deter most players.


### Movement

- Third person is new and needs to be tested.
  - The big thing about third person is it allows us to see outside of the current maps zones a little bit, even if we keep the camera close in. That might not be an issue as we can just turn the boundries into slightly more 3D areas (like extending buildings or trees a bit off the map) and then just not rendering the other zones.
  - This also might affect PvP a little bit, but I think probably in a good way. Or at least I think it will be worth the cost.
  - We will probably want to keep the 3rd person camera in tight to the player and probably locked in place so they can't manuver the camera too much.
  
- Jumping. The old game did not have any jump, but I think perhaps we might want some kind of jump mechanic? Let's think about this and figure out if we want to include the jump and then account for it around the world, or just remove it and have the movement work like the old game where "jumps" were just straight movements and falling to get to the secret places.
  - I think allowing players to jump to more easily access a lot of places isn't a bad idea except in a few key areas.
